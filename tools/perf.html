Riptide Rush: frame benchmark

Draws a full game frame through src/render.js (drawFrame): 200 enemies in a mix of kinds, 60 bullets, a player, and a steady heavy-effects load (kill bursts, multi-kill shards, trails, floaters) from src/fx.js, on a 1920x1080 backing canvas. Each frame ends with a 1x1 getImageData so the time includes the canvas raster. The scene is deterministic: the same seeds, the same fixed 60 Hz effects step, so before and after runs draw the same frames. Results go to window.__perf after the warm-up. ?frames=N sets the measured frame count (default 300); ?warm=N sets the warm-up (default 120).
